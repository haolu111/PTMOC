# PTMOC 轨迹可视化验证系统需求分析文档

## 1. 目的

轨迹上传
推荐轨迹选择，可以就是现有的一段样例路径，便于展示，不那么复杂
DTLW 路径匹配（这部分来自我附上的三张图片，需要ai完成）
PTMOC 加密域验证，计算和推荐路径的差异是否很大
结果地图展示

系统实现层
用户端：前端页面，负责上传轨迹、展示结果
服务器端：就是后台，负责解析数据、执行 DTLW、调用 PTMOC、返回结果

## 4. 建设目标与范围

### 4.1 目标

- 提供用户友好的轨迹上传与验证体验。
- 支持轨迹数据预览、格式校验与地图可视化。
- 支持后端接入 PTMOC 算法进行加密域验证。
- 支持返回可解释的验证结果，而不仅是“通过/不通过”。

## 6. 业务场景与用户流程

### 6.1 核心业务场景

场景一：用户上传一段轨迹，验证其是否满足预设轨迹规则或参考轨迹要求。

场景二：用户在地图中查看原始轨迹与验证结果轨迹的差异，如偏移段、异常点、未命中区间。

场景三：管理员查看任务执行记录、算法运行状态和失败原因。

### 6.2 标准业务流程

1. 用户进入验证页面。
2. 选择输入方式：文件上传 / 粘贴 JSON / 示例数据。
3. 系统完成格式校验与轨迹预览。
4. 用户选择验证配置：
   - 验证规则类型
   - 阈值参数 `k`
   - 参考轨迹或参考区域
5. 用户点击“开始验证”。
6. 后端创建任务并完成：
   - 数据预处理
   - 消息编码
   - PTMOC 加密
   - 密文域验证
   - 结果恢复/解读
7. 前端轮询或通过 WebSocket 获取任务进度。
8. 验证完成后展示：
   - 总体结果
   - 地图对比
   - 轨迹命中率/相似度/异常段
   - 算法执行摘要
9. 用户可导出报告或再次发起验证。

## 8. 功能需求

## 8.1 轨迹数据输入

### 8.1.1 输入方式

系统应支持以下输入方式：

- 上传 CSV 文件
- 上传 JSON 文件
- 文本框粘贴 JSON 数据
- 一键载入示例数

### 8.1.4 用户交互要求

- 上传后自动显示解析结果摘要
- 错误信息要具体到行号、字段名、原因
- 提供模板下载
- 支持清空并重新上传

## 8.3 验证任务发起

用户在发起验证时可配置：

- 任务名称
- 输入方式
- 参考轨迹 / 参考区域 / 参考规则
- 阈值参数 `k`
- 验证函数类型
- 是否保存原始文件

验证函数类型建议至少支持以下三类：

- 轨迹相似度验证
- 区域命中验证
- 轨迹完整性/合规性验证

说明：具体函数实现最终由 `EvalModule.evaluate` 承担，但前端和业务后端需要以统一枚举管理。

## 8.5 密文域验证

### 8.5.1 验证目标

服务端需要在不直接暴露原始轨迹明文的情况下，对轨迹进行验证，并生成用户可理解的结论。

### 8.5.2 验证输出

后端最终至少返回：

- `verificationStatus`：通过 / 不通过 / 部分通过 / 失败
- `score`：数值化评分
- `matchedSegments`：命中轨迹段
- `abnormalSegments`：异常轨迹段
- `abnormalPoints`：异常点列表
- `reasonCodes`：失败原因码
- `algorithmSummary`：算法执行摘要

### 8.5.3 结果解释层要求

算法输出往往偏底层，业务后端需要增加“解释层”，把密文域验证结果翻译为前端可直接展示的数据：

- 轨迹偏移距离
- 偏移起止点
- 偏移占比
- 是否进入非法区域
- 与参考轨迹的覆盖率

## 8.6 可视化展示

### 8.6.1 页面布局要求

参考之前中期提供的示意图，首页采用“双地图对比 + 顶部操作区 + 侧边结果区”的结构：

- 左侧地图：原始上传轨迹
- 右侧地图：验证结果轨迹
- 顶部：上传方式切换、任务参数设置、开始验证按钮
- 侧边栏：任务状态、结果摘要、异常信息、导出按钮


## 9. 前端需求详细说明

## 9.1 页面清单

建议前端至少包含以下页面：

| 页面 | 用途 |
| --- | --- |
| 验证首页 | 上传数据、配置参数、启动验证 |
| 任务详情页 | 展示地图对比和验证结论 |
| 历史任务页 | 查询历史记录 |
| 管理页 | 配置参考轨迹和系统参数 |

## 9.2 验证首页组件

- 顶部标题区
- 输入方式切换 Tab
- 文件上传组件
- JSON 输入框
- 示例数据按钮
- 参数表单区
- 开始验证按钮
- 数据解析摘要卡片
- 地图预览区

## 9.3 交互要求

- 上传成功后自动预览轨迹
- 参数未填完整时禁用“开始验证”
- 启动任务后显示进度状态，不允许重复提交
- 失败时支持一键重试
- 地图上点选异常点时同步高亮列表项
